# Disney Companion

GitHub Pagesで公開できる試作版です。

## 含まれる機能
- TODAY'S PLAN
- 予定追加・編集・完了チェック
- NEXT表示
- 共有時点のプランをURLで共有
- フード検索のサンプル
- フードからプランへ追加

## GitHub Pages
リポジトリ直下に以下4ファイルをアップロードしてください。

- index.html
- styles.css
- app.js
- manifest.webmanifest

Settings → Pages → Deploy from a branch → main / root を選択します。
